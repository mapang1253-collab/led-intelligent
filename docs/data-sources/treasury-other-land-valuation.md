> เอกสารนี้เป็น **หลักฐานที่มีวันที่** ไม่ใช่การอนุญาตให้เปิดใช้งาน การ activate ต้องผ่าน gate ใน

## 1. ทำไมถึงเลือกชุดนี้ ไม่ใช่ราคาประเมินที่ดินรายแปลง

กรมธนารักษ์เผยแพร่ราคาประเมินที่ดิน **รายแปลง** ด้วย แต่ใช้ไม่ได้กับระบบนี้:

| | ราคาประเมินที่ดิน (รายแปลง) | **ราคาประเมินทุนทรัพย์ที่ดินประเภทอื่น** |
|---|---|---|
| ขนาด | **1.44 GB** (77 ไฟล์) | **5.1 MB** (ไฟล์เดียว) |
| แถว | ~50 ล้าน (ชลบุรีอย่างเดียว 984,881) | 31,999 |
| ชื่อตำบล/อำเภอ | **ไม่มี** | **มี พร้อมรหัส** |
| ค้นหาจากพื้นที่ | ไม่ได้ ต้องใช้เลขระวาง + เลขที่ดินจากโฉนด | ได้ |

ชุดรายแปลงเกินโควตา Supabase free tier (500MB) และไม่มีทางเชื่อมกับพื้นที่ที่ผู้ใช้เลือกได้
จึงเลือกชุดนี้ ซึ่งแลกมาด้วยข้อจำกัดเรื่องขอบเขตในข้อ 6

## 3. หน่วยของราคา — ข้อที่ต้องตรวจให้แน่ที่สุด

metadata ของแหล่ง **ไม่ระบุหน่วย** และถ้าเดาผิดระหว่างบาทต่อตารางวากับบาทต่อไร่
มูลค่าที่คำนวณได้จะคลาดเคลื่อน **400 เท่า**

**สรุป: บาทต่อตารางวา** โดยมีหลักฐานสองทางที่สอดคล้องกัน

**ก. เอกสารของกรมธนารักษ์เอง** — "สรุปราคาประเมินที่ดินรายหน่วยที่ดิน รอบบัญชี พ.ศ. 2566–2569"
(จังหวัดสุราษฎร์ธานี) ใช้หัวตารางว่า

> ลำดับที่ | ชื่อหน่วยที่ดิน | **ราคาประเมิน (บาท / ตารางวา)**

ปรากฏ **232 ครั้ง** ตลอดเอกสาร 832 KB และไม่มีหัวตาราง "ต่อไร่" เลย (คำว่า "ไร่" ที่พบทั้ง 32 ครั้ง
เป็นชื่อสถานที่ เช่น บ้านไร่เหนือ ซอยไร่ศรีทอง) เอกสารนี้ใช้แนวคิด **หน่วยที่ดิน** แบบเดียวกับไฟล์ของเรา

**ข. ขนาดของตัวเลขสอดคล้องกัน** — เอกสารข้างต้นให้ราคาถนนชนบทในสุราษฎร์ธานีที่ 300 / 630 / 750 /
1,000 บาทต่อตารางวา ส่วนไฟล์ของเราให้ค่ามัธยฐานของสุราษฎร์ธานีที่ **500** อยู่ในย่านเดียวกันพอดี

ถ้าตีความเป็นบาทต่อไร่ ค่ามัธยฐานทั้งประเทศ 350 บาท/ไร่ จะเท่ากับที่ดินหนึ่งไร่ราคา 350 บาท
และค่าสูงสุด 120,000 บาท/ไร่ ที่ที่ดินติดทางหลวงในเทศบาลตำบลสำโรงเหนือ จะเท่ากับ 300 บาท/ตารางวา
ซึ่งต่ำกว่าความเป็นจริงราวสองเท่าของสิบ — ตีความแบบนี้ขัดกับเอกสารของกรมธนารักษ์เอง

## 4. การจับคู่กับเขตการปกครอง

รหัสประกอบกันแบบเดียวกับไฟล์อาคารชุด (เติมศูนย์ให้ครบสองหลักก่อนต่อกัน)

**ผลการจับคู่ (17 ก.ย. 2569): 31,971 จาก 31,971 รายการ — ไม่ทิ้งเลยสักแถว**

| | รายการ |
|---|---|
| จับคู่ถึงระดับตำบล | 21,776 |
| วางที่ระดับอำเภอ | 10,195 |

หนึ่งในสามของไฟล์เป็น **เทศบาล** — `TUMBON_NAME` เป็น "เทศบาลตำบลโคกตูม", "เทศบาลเมืองลัดหลวง"
และหลักที่หกของรหัสเป็นเลขเทศบาล ไม่ใช่เลขตำบล (เช่น 96, 97, 99) รหัสเหล่านี้ไม่มีคู่ในตารางอ้างอิง

ทางเลือกคือทิ้ง 10,195 รายการ หรือวางไว้ที่ **อำเภอ** ซึ่งรู้แน่นอนจากรหัสสี่หลักแรก
เลือกอย่างหลัง และติดป้ายว่าเป็นข้อมูลระดับอำเภอ — การเดาว่าเทศบาลนั้นอยู่ตำบลใดในอำเภอ
จะเป็นการสร้างความละเอียดที่ไฟล์ไม่มี

## 5. การแปลงเป็น Observation

หนึ่ง Observation ต่อ **หน่วยที่ดิน × พื้นที่** — 31,971 รายการ

**19 คู่มีราคาต่างกันภายใต้ชื่อหน่วยที่ดินเดียวกันในพื้นที่เดียวกัน** เช่น เทศบาลตำบลโคกตูม ลพบุรี
มี `ที่ดินติดทางหลวงแผ่นดิน` ทั้งราคา 500 และ 2,000 กรมธนารักษ์ประกาศราคาแยกตามบล็อก
แต่ไฟล์ที่ถูก flatten แล้วไม่มีคอลัมน์บอกว่าแถวไหนเป็นบล็อกไหน

- เลือกค่าใดค่าหนึ่ง → เป็นการโยนหัวก้อยแล้วนำเสนอเป็นข้อเท็จจริง
- เฉลี่ย → สร้างตัวเลขที่ไม่มีใครประกาศ

จึงเก็บเป็น **ช่วงราคา** พร้อมจำนวนบล็อกติดไปกับชื่อกลุ่ม และ **ห้ามนำไปคูณกับเนื้อที่**
เพราะไม่มีอัตราเดียวที่ใช้ได้ — หน้าจอจะบอกเหตุผลแทนการคำนวณ

## 6. ข้อจำกัดที่ต้องแสดงต่อผู้ใช้ — ข้อแรกสำคัญที่สุด

1. **เป็นราคาของที่ดินที่มีเอกสารสิทธิประเภทอื่น ไม่ใช่ที่ดินมีโฉนด** ที่ดินในเขตเมืองส่วนใหญ่เป็นโฉนด
   จึงไม่มีข้อมูลในชุดนี้ — ตรวจแล้วว่า ต.บางปลาสร้อย (เขตเมืองชลบุรี) ไม่มีสักแถว
   **ผู้ใช้ที่ถือโฉนดกำลังดูตัวเลขที่ไม่ใช่ของที่ดินตนเอง** ระบบจึงแสดงคำเตือนนี้ก่อนตัวเลขเสมอ
2. **ไม่มีข้อมูลกรุงเทพมหานครเลย**
3. **ราคาแยกตามหน่วยที่ดิน ไม่ใช่รายแปลง** ผู้ใช้ต้องรู้เองว่าที่ดินตนอยู่ในหน่วยใด
4. **1 ใน 3 ของข้อมูลอยู่ที่ระดับอำเภอ** ไม่ใช่ระดับตำบล
5. **19 หน่วยที่ดินมีช่วงราคา** ใช้คำนวณมูลค่าไม่ได้ เพราะไม่มีอัตราเดียวที่ใช้ได้
6. **ไม่ใช่ราคาตลาด** เป็นฐานสำหรับภาษีและค่าธรรมเนียมการโอน
