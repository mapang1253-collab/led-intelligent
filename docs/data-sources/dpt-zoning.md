# ผังเมืองรวม — กรมโยธาธิการและผังเมือง (DPT)

**เอกสารนี้เป็นบันทึกการตรวจสอบที่มีวันที่ ไม่ใช่คำสั่ง และไม่ได้ activate อะไร**
สถานะการใช้งานจริงถูกกำหนดโดย [ADR 0008](../adr/0008-dpt-zoning-context.md): แสดงเป็นบริบทประกอบ
ไม่เข้าสู่การวิเคราะห์ ไม่สร้าง Observation

ตรวจสอบเมื่อ: **2026-09-26**

## สิ่งที่ค้นหาและไม่พบ

ค้นบน data.go.th ด้วยคำว่า "ผังเมือง" พบ 105 ชุดข้อมูล ส่วนใหญ่เป็น PDF/CSV ของกฎกระทรวง ไม่ใช่รูปหลายเหลี่ยม
ชุดที่ชื่อ `ขอบเขตผังเมือง` ของกรมโยธาธิการและผังเมืองเป็น JSON แต่ **ลิงก์ดาวน์โหลดตอบ
`{"returnCode":"99","returnMessage":"Token Fail or Token Expire"}`** — token ที่ฝังไว้ใน CKAN หมดอายุแล้ว
จึงใช้ไม่ได้

ช่องทางที่ใช้ได้จริงคือบริการเบื้องหลังระบบ "ตรวจสอบผังการใช้ประโยชน์ที่ดิน" ของกรมฯ เอง
(<https://plludds.dpt.go.th/landuse/>) ซึ่งเปิดสาธารณะ ไม่ต้องล็อกอิน ไม่มี bot protection
และไม่มี API key — พบจาก `maps/js/config.js` และ `maps/js/mymap.js` ของหน้าเว็บนั้น

## บริการที่ใช้

### 1. รูปหลายเหลี่ยมโซน + สี — ArcGIS

```text
https://dptgis.dpt.go.th/arcgis/rest/services/dds2/PLLU<รหัสจังหวัด 2 หลัก>/MapServer
```

- หนึ่งบริการต่อหนึ่งจังหวัด มี **75 บริการ** (ขาดกรุงเทพมหานคร `10` และนนทบุรี `12`)
- ภายในแต่ละบริการมีหลายชั้น ชื่อขึ้นต้นด้วย
  - `PLLU_<รหัสผัง>` = ผังการใช้ประโยชน์ที่ดิน (ที่ใช้)
  - `PLRC_<รหัสผัง>` = ผังคมนาคมและขนส่ง (ไม่ใช้ คนละคำถาม)
  - `LAW<รหัสจังหวัด>`, `PARCEL<รหัส>`, `COMP_BND<รหัส>` (ไม่ใช้)
- รหัสผัง `<จังหวัด>99000` หรือ `<จังหวัด>00000` คือผังเมืองรวมจังหวัด ส่วน `<จังหวัด>0NN0N` คือผังเมืองรวมเมือง/ชุมชน
  หลายจังหวัดมีทั้งสองแบบทับกัน — เช่น สันทราย เชียงใหม่ อยู่ในทั้งผังเมืองรวมเมืองและผังจังหวัด
- ฟิลด์ที่ใช้: `PL_USE` (รหัสประเภทที่ดิน), `PL_DESC` (ชื่อไทย — **ผังรุ่นเก่าไม่มีฟิลด์นี้**),
  `PL_BLOCK` (หมายเลขบริเวณ เช่น `พ.-4`), `CB_ID` (รหัสผัง)
- สีทางการอ่านจาก `MapServer/<layer>?f=json` → `drawingInfo.renderer.uniqueValueInfos[].symbol.color`
  เป็น `[r,g,b,a]` โดย `a = 0` หมายถึงวาดแบบไม่ถมสี
- ค้นด้วย `identify` พร้อม `tolerance=0` เพื่อให้ได้เฉพาะรูปหลายเหลี่ยมที่ **มีจุดนั้นอยู่ข้างในจริง**
  `tolerance=1` กินพื้นที่ราว 18 เมตรและคืนโซนข้างเคียงมาด้วย (ทดสอบที่สระบุรี)
- ภาพสีผังเมืองสำหรับซ้อนบนแผนที่ใช้ `MapServer/export` โดยส่ง bbox เป็นเมตรแบบ Web Mercator ต่อหนึ่ง tile
  เบราว์เซอร์เรียกภาพเอง ไม่ผ่าน Worker

### 2. ข้อกำหนดและข้อห้าม — PHP

```text
https://plludds.dpt.go.th/landuse/maps/script/querydb_landuse.php?cbid=<รหัสผัง>&usecode=<PL_USE>
https://plludds.dpt.go.th/landuse/maps/script/querydb_landuse_prohibition.php?cbid=<รหัสผัง>&usecode=<PL_USE>
https://plludds.dpt.go.th/landuse/maps/script/get_legend_pllu.php?cbid=<รหัสผัง>
```

- ทั้งสามตัวคืน **HTML ที่จัดรูปแล้ว** ไม่ใช่ JSON ข้อความจริงอยู่ใน `<div>` สุดท้ายที่มี `margin-left: 20px`
  แต่ละข้อคั่นด้วย `<br>`
- `get_legend_pllu.php` ให้คู่ รหัส ↔ ชื่อไทย โดยรหัสอยู่ในชื่อไฟล์ภาพ `Usecode/<PL_USE>.png`
  ใช้เป็นทางสำรองเมื่อข้อมูลไม่มี `PL_DESC`
- **ห้ามใช้** `query_landuse_ruletype.php` และ `api/mobile/v1/FindLocation` — ตัวหลังตอบ HTTP 502
  ตั้งแต่วันที่ตรวจ และตัวแรกเรียกต่อไปยังตัวหลัง จึงพ่น warning ของ PHP ออกมาในผลลัพธ์

## สิทธิ์การใช้งาน

ชุดข้อมูล `ขอบเขตผังเมือง` บน data.go.th ระบุสัญญาอนุญาต **Creative Commons Attributions**
ส่วน `ผังเมืองรวมที่ประกาศตามกฎกระทรวง` และ `รายชื่อผังเมืองที่ประกาศบังคับใช้` ระบุ **Open Data Common**
บริการแผนที่ข้างต้นเปิดสาธารณะโดยไม่มีเงื่อนไขการเข้าถึง หน้าจอจึงแสดงที่มาว่า
"ข้อมูลผังเมืองรวมจากกรมโยธาธิการและผังเมือง (ระบบ DDS Explorer)" ทุกครั้ง พร้อมลิงก์กลับไปยังระบบของกรมฯ

## ผลการทดสอบ 2026-09-26

สุ่ม 20 จุดทั่วประเทศ ได้โซนจริง 17 จุด ตัวอย่าง:

| จุด | ผลที่ได้ |
|---|---|
| ต.หนองปรือ อ.บางละมุง ชลบุรี | ศูนย์กลางพาณิชยกรรม `พ.-4` `#e60000` ห้าม 6 ข้อ |
| เมืองเชียงใหม่ | ชุมชน `1.11` `#f57d96` ห้าม 4 ข้อ |
| หาดใหญ่ สงขลา | ชุมชน `1.8` `#f57d96` ห้าม 7 ข้อ |
| เมืองขอนแก่น | ชุมชน `1.17` `#f57d96` ห้าม 12 ข้อ |
| เมืองภูเก็ต | พาณิชยกรรมและที่อยู่อาศัยหนาแน่นมาก `3.13` `#ff0000` ห้าม 9 ข้อ |
| สันทราย เชียงใหม่ | **สองผัง**: ที่อยู่อาศัยหนาแน่นน้อย `2.12` + ชุมชน `1.11` |
| นนทบุรี | ไม่มีบริการ → รายงานว่ายังไม่ได้เผยแพร่ |

อีก 3 จุดที่ได้ "ไม่อยู่ในผัง" (เมืองเชียงราย เมืองนครราชสีมา หัวหิน) เกิดจากพิกัดตกร่องถนนหรือแหล่งน้ำ
ขยับไปไม่กี่สิบเมตรพบโซนทั้งสามจุด
