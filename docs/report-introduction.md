## 1.1 ความเป็นมาและความสำคัญของปัญหา

การตัดสินใจว่าที่ดินแปลงหนึ่งควรใช้ประโยชน์ในรูปแบบใดจึงจะเหมาะสมที่สุด คือการวิเคราะห์
การใช้ประโยชน์สูงสุดและดีที่สุด (Highest and Best Use) ซึ่งพิจารณาความเป็นไปได้ทางกฎหมาย
ทางกายภาพ ทางการเงิน และการให้ผลตอบแทนสูงสุดประกอบกัน

ข้อมูลที่จำเป็นต่อการวิเคราะห์ดังกล่าวมีเผยแพร่อยู่แล้ว แต่กระจายอยู่ในหน่วยงานภาครัฐอย่างน้อย
ห้าแห่ง ได้แก่ กรมธนารักษ์ (ราคาประเมินที่ดิน สิ่งปลูกสร้าง และอาคารชุด) กรมโยธาธิการและผังเมือง
(ผังเมืองรวม) กรมที่ดิน (รูปแปลง) กรมการปกครอง (ประชากร) และสำนักงานสถิติแห่งชาติ
(รายได้ครัวเรือน) แต่ละแห่งใช้ชื่อเรียกพื้นที่ หน่วยวัด และปีข้อมูลที่ไม่สอดคล้องกัน
ผู้ที่มิได้เป็นผู้เชี่ยวชาญจึงไม่สามารถนำมาเทียบเคียงกันได้

ขณะที่บริการเชิงพาณิชย์ที่มีอยู่มุ่งนำเสนอราคาเสนอขายในตลาด ซึ่งเป็นคนละคำถามกับว่าที่ดินแปลงนั้น
**ทำอะไรได้ตามกฎหมาย** และโดยทั่วไปไม่แสดงแหล่งที่มา ปีข้อมูล หรือข้อจำกัดของชุดข้อมูล
ผู้ใช้จึงตรวจสอบย้อนกลับไม่ได้ว่าข้อสรุปตั้งอยู่บนหลักฐานใด

โครงงานนี้จึงพัฒนาระบบที่รวบรวมหลักฐานจากหน่วยงานภาครัฐไว้ในที่เดียว ประมวลผลตามลำดับ
การวิเคราะห์ HBU และแสดงขอบเขตของสิ่งที่ข้อมูลตอบได้และตอบไม่ได้อย่างชัดเจน

## 1.2 วัตถุประสงค์ของโครงงาน

1. รวบรวมราคาประเมินของทางราชการ ข้อมูลประชากร รายได้ครัวเรือน และผังเมืองรวมของพื้นที่เป้าหมาย
   ไว้ในที่เดียว โดยคงการอ้างอิงแหล่งที่มา ปีข้อมูล และข้อจำกัดของทุกรายการ
2. ออกแบบกระบวนการที่ให้ปัญญาประดิษฐ์เป็นผู้เสนอแนวคิด และให้ชุดกฎแบบกำหนดผลตายตัวเป็นผู้ตรวจสอบ
   โดยปัญญาประดิษฐ์ไม่มีอำนาจตัดสินความถูกต้องตามกฎหมายและแก้ผลการตรวจสอบไม่ได้
3. พัฒนากลไกให้ระบบรายงานสถานะ "ยังตรวจสอบไม่ได้" อย่างตรงไปตรงมา พร้อมระบุว่าขาดข้อมูลใด
   และต้องได้มาจากแหล่งใด แทนการประมาณค่าเพื่อให้ผลลัพธ์ดูสมบูรณ์
4. ให้ใช้งานได้ครอบคลุมทุกจังหวัด โดยไม่ต้องลงทะเบียนและไม่เก็บข้อมูลผู้ใช้เกินจำเป็น

| การสรุปความคุ้มค่าจากหลักฐาน | เครื่องคำนวณความเป็นไปได้ทางการเงินเบื้องต้นใช้งานได้ แต่คำนวณจากสมมติฐานที่ผู้ใช้ระบุเอง ไม่ได้ดึงจากหลักฐาน จึงไม่มีผลต่อสถานะสุดท้าย ซึ่งยังเป็น "หลักฐานไม่เพียงพอ" ทุกกรณี |

## 1.4 ประโยชน์ที่คาดว่าจะได้รับ

1. ผู้ถือครองหรือผู้พิจารณาที่ดินเห็นราคาประเมินของทางราชการ ผังเมืองรวม และข้อกำหนด
   ทางกฎหมายของพื้นที่นั้นได้จากจุดเดียว
2. ผู้ใช้ทราบขอบเขตของข้อสรุป เพราะระบบระบุแหล่งที่มา ปีข้อมูล และข้อจำกัดของทุกตัวเลข
   พร้อมแจ้งประเด็นที่ข้อมูลยังไม่เพียงพอ
3. ได้ต้นแบบสถาปัตยกรรมที่แยกบทบาทระหว่างปัญญาประดิษฐ์ในฐานะผู้เสนอ กับชุดกฎในฐานะผู้ตรวจสอบ
   ซึ่งนำไปประยุกต์กับงานที่ต้องการความสามารถในการตรวจสอบย้อนกลับในสาขาอื่นได้

## 1.5 นิยามศัพท์เฉพาะ

| คำ | ความหมายที่ใช้ในโครงงานนี้ |
|---|---|
| **การใช้ประโยชน์สูงสุดและดีที่สุด** (HBU) | การใช้ประโยชน์ที่เป็นไปได้ทั้งทางกฎหมาย กายภาพ และการเงิน และให้ผลตอบแทนสูงสุด |
| **ราคาประเมินทุนทรัพย์** | ราคาที่กรมธนารักษ์กำหนดเพื่อจัดเก็บภาษีและค่าธรรมเนียม มิใช่ราคาซื้อขายในตลาด |
| **สถานะการตรวจสอบ** | ผลการตรวจกฎแต่ละข้อ มีสี่สถานะ คือ ผ่าน ไม่ผ่าน ผ่านบางส่วน และยังตรวจไม่ได้ โดยสถานะ "ยังตรวจไม่ได้" แปลงเป็น "ผ่าน" หรือ "ไม่ผ่าน" ไม่ได้ |
| **ACADEMIC_REVIEWED** | สถานะของชุดกฎที่ผ่านการตรวจทานเชิงวิชาการและบันทึกชื่อผู้ตรวจแล้ว มิใช่การรับรองระดับวิชาชีพ ระบบประมวลผลเฉพาะชุดที่มีสถานะนี้ |

"คำถามของโครงงาน" แทน เช่น *ระบบที่รายงานขอบเขตของความไม่รู้อย่างตรงไปตรงมา จะให้ประโยชน์
