## หน้า 1 — สไลด์เปิด

เปลี่ยนท้ายย่อหน้าที่สอง จากเดิมที่ลงท้ายว่า "ด้านการลงทุนอสังหาริมทรัพย์ได้สะดวกและเป็นระบบมากขึ้น"

```
โครงการนี้เป็นการประยุกต์ใช้แนวคิด Financial Technology หรือ FinTech โดยนำเทคโนโลยีดิจิทัลและ AI มาช่วยวิเคราะห์ข้อมูล เพื่อให้ผู้ใช้งานมีข้อมูลประกอบการตัดสินใจเรื่องการใช้ประโยชน์ที่ดินได้สะดวกและเป็นระบบมากขึ้น
```

เหตุผล: ระบบประกาศทุกหน้าว่าไม่ให้คำแนะนำการลงทุน สไลด์แรกจึงไม่ควรเปิดด้วยคำนั้น

## หน้า 16 — Business Model

**กล่อง "ข้อได้เปรียบและความเสี่ยง"**

```
จุดเด่นคือครอบคลุม 77 จังหวัด ข้อมูลตรวจสอบย้อนกลับได้ และชุดกฎผ่านการตรวจทานเชิงวิชาการพร้อมบันทึกวันที่ตรวจ แสดงข้อจำกัดและปีข้อมูลอย่างชัดเจน เพื่อลดความเสี่ยงจากข้อมูลที่ไม่ถูกต้องหรือล้าสมัย
```

เหตุผล: ชุดกฎอยู่ในสถานะ `ACADEMIC_REVIEWED` ซึ่งเราประกาศเองว่าไม่ใช่การรับรองระดับวิชาชีพ คำว่า "ผู้เชี่ยวชาญ" จึงขัดกับคำปฏิเสธความรับผิดชอบที่ขึ้นบนหน้าจอทุกหน้า

**กล่อง "ช่องทางสร้างรายได้"**

```
สร้างรายได้จากการขายชุดกฎที่เครื่องอ่านได้ให้ภาคธุรกิจและภาครัฐ ซึ่งทำได้ทันทีภายใต้ระบบปัจจุบัน ส่วนค่าบริการรายเดือน การขายรายงาน และ API ต้องปรับสถาปัตยกรรมก่อน เพราะระบบปัจจุบันไม่มีบัญชีผู้ใช้และไม่มีไฟล์ส่งออกโดยการออกแบบ
```

```

```
